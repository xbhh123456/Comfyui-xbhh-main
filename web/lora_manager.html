                配置 API 密钥（Personal Access Token）可解锁 Civitai 受限/R18/会员模型的推荐触发词拉取，并提升 API 请求额度。
              

              

                
                  
                  获取 API Key 教程（点击展开/收起）
                

                  获取步骤：
                  登录 Civitai 账号设置页
                  → 往下翻到「API Keys」→ 填写名称 → Add API Key → 复制生成的长字符串粘贴到下方。

                  
                    
                    Token 只显示一次，请妥善保存；填错也能保存但拉取时会失败，请务必先点「保存并测试」验证。

                  单个 LoRA 卡片大小（图标视图）160 px

                
拖动滑块调整图标视图下每个 LoRA 卡片的占位宽度，只会停在固定档位上，实时生效。
